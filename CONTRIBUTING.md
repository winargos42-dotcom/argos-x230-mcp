# Contributing

Спасибо за вклад в ARGOS X230 MCP.

1. Создайте issue с понятным воспроизводимым сценарием и ожидаемым поведением.
2. Сделайте отдельную ветку и минимальный патч.
3. Добавьте отрицательные тесты: запрет путей вне workspace, сетевого доступа, сторонних shell-команд и запуска при дефиците ресурсов.
4. Запустите `python -m unittest discover -s tests -v` и `python -m compileall -q src`.
5. Отправьте PR. Не прикладывайте креденшелы Cloudflare, Bearer-токены, логи с персональной информацией или скриншоты секретных панелей.

Цель — надёжный инструмент для обычных Linux-пользователей, а не расширение полномочий агентов любой ценой. Новые опасные действия должны требовать отдельной авторизации и аудита.
